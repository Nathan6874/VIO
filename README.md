# VIO

VIO est une plateforme immobilière permettant de découvrir des biens
et de les visiter à distance grâce à des visites virtuelles à 360°.

## Technologies

- Backend : Java 17 et Spring Boot
- Frontend : Angular
- Base de données : PostgreSQL
- Gestion des versions : Git
- Conteneurisation : Docker

## Structure

- backend/ : application Spring Boot
- frontend/ : application Angular
- docs/ : documentation du projet
